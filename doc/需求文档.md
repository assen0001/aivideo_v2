## 1. 项目概述

### 1.1 项目背景

- 随着 AIGC 技术成熟（ComfyUI、Stable Diffusion、Wan2.2 等开源模型），视频内容创作门槛大幅降低；
- 市面上缺乏「剧本创作 → 文生图 → 图生视频 → 配音合成 → 最终成片」全链路打通的一站式解决方案；
- 现有工具流程碎片化、依赖云端 API（隐私/成本问题）、ComfyUI 工作流配置复杂。

**痛点分析：**

| 痛点 | 说明 |
|:----|:-----|
| 流程碎片化 | 剧本、图像、视频、配音各环节工具分散，手动搬运效率低 |
| 云端依赖 | 多数 AI 视频工具依赖云端 API，数据隐私难保障、成本高 |
| 配置复杂 | ComfyUI 工作流手动配置繁琐，非技术人员难以使用 |
| 多模型协同难 | 文生图、图生视频、语音合成等多个模型需协调工作 |

### 1.2 产品定位与目标

**一句话目标：** 将本地视频智造平台（aivideo）升级为 V2.0：以 **SQLite 为唯一数据源**，交付「认证 + 左右工作台 + 创作/项目/资产/教程/配置五页面」的单管理员本地化视频创作平台；支持**语音驱动视频时长**与**无配音模式**。

**项目最大亮点：** 可本地部署的 AI 长视频创作平台 —— 大语言模型（Qwen）、文生图（z-image-turbo）、图生视频（Wan2.2 I2V）、语音合成（IndexTTS）**全链路模型均支持本地化部署**，无须申请任何第三方平台 API 接口，**0 成本创作 AI 长视频**；数据全程不出本地，可完全离线运行。

**产品目标：**

| 编号 | 目标 |
|:----:|:-----|
| G1 | 全流程自动化：用户仅需输入主题与配置，一键生成视频 |
| G2 | 全链路打通：剧本→文生图→图生视频→语音→合成，无需人工干预 |
| G3 | 多样化输出：多比例、多分辨率、8 种画面风格、5 种音色（另支持无配音） |
| G4 | 过程可感知：生成过程中实时展示各步骤进度 |
| G5 | 结果可获取：成品视频支持在线预览与下载 |
| G6 | 可运行性：FFmpeg 需用户自行下载（放入 video-platform/bin/ 或配置系统 PATH），程序按「内置 bin → PATH」查找并给出配置指引 |
| G7 | 全本地化部署：四大 AI 模型本地运行，零 API 依赖、0 成本创作、可离线使用 |

### 1.3 用户特征

| 用户角色 | 特征 | 典型场景 | 使用频率 |
|:---------|:-----|:---------|:---------|
| 短视频创作者 | 非技术背景，追求效率 | 批量产出短视频素材 | 每日 |
| 教育工作者 | 非技术背景 | 制作教学/宣传视频 | 每周 |
| 市场营销人员 | 非技术背景 | 快速生成产品宣传片 | 按需 |
| AI 技术爱好者 | 技术背景 | 研究 AI 视频生成技术 | 不定期 |

> 部署形态：**单用户本地化部署**，仅 1 个管理员账号。

### 1.4 术语定义

| 术语 | 说明 |
|:-----|:-----|
| ComfyUI | 基于节点式工作流的 AI 图像/视频生成引擎（本项目拆分文生图/图生视频两个服务） |
| Wan2.2 | 开源的图生视频模型（high/low noise 双模型 + LightX2V LoRA） |
| z-image-turbo | 文生图模型 |
| T2I / I2V | Text to Image（文生图）/ Image to Video（图生视频） |
| TTS | Text to Speech，文本转语音 |
| Agent | 承担单一 AI 任务的处理单元 |
| 分镜（Scene） | 视频的单个场景片段，包含画面描述、旁白、字幕、提示词 |
| 管线（Pipeline） | 剧本→语音→图片→视频→合成 的完整处理链路（语音前置） |
| LLM | 大语言模型，用于剧本创作 |

## 2. 设计原则与范围

### 2.1 设计原则（领导已拍板）

| # | 决策 | 结论 |
|:--:|:-----|:-----|
| 1 | 部署形态 | **单用户本地化部署**，仅 1 个管理员账号 |
| 2 | 数据存储 | **SQLite 为唯一数据源**，全部数据以数据库为准（**不保留 script.json**） |
| 3 | 首次登录 | 用户表为空 → 初始化面板（用户名/密码/确认密码，无验证码）→ 创建即登录 |
| 4 | 常规登录 | 用户名 + 密码 + **6 位纯数字验证码**；密码加密保存 |
| 5 | 重置密码 | 用户名 + 新密码 + 确认密码 → 保存成功并提示 |
| 6 | 创作并发 | **同一时间仅允许 1 个项目在创作**；SQLite 锁表时间要短 |
| 7 | 存量项目 | **不回填、不迁移**，以新项目为设计原则（旧数据可清理） |
| 8 | 删除级联 | 删除记录时**同步物理删除原文件**，删除前弹窗确认 |
| 9 | 教程 | 存 SQLite（Markdown）；**直接发布、无草稿态**；阅读页渲染；**初始内容全部导入 doc/ 现有文档** |
| 10 | 资产 | **增删改查**：上传/列表/打开下载/重命名/删除；**不做在线预览**，点击链接由浏览器决定打开或下载；大小限制与扩展名白名单**从 SQLite 配置表读取** |
| 11 | 封面 | 项目封面 = 第 1 个分镜图片 |
| 12 | 官网 | `https://aivideo.site`（头像菜单「进入官网」） |
| 13 | 技术选型 | **方案 A：Vue3 重构**（Vue3.5 + TS） |
| 14 | 字体 | 全部开源/免费可商用 |
| 15 | 新增「配置」导航 | 配置页维护系统常量参数（LLM / 文生图 / 图生视频 / TTS / 上传限制），存 SQLite 配置表 |
| 16 | FFmpeg | 用户自行下载 `ffmpeg.exe/ffprobe.exe`（LGPL 许可，不随仓库分发）：放入 `video-platform/bin/` 或加入系统 PATH；**代码按「内置 bin → 系统 PATH」查找，均无则报错提示配置** |
| 17 | 主程序名 | `backend_main.py` **改名为 `main.py`**（同步 start.bat 与文档引用） |
| 18 | 登录安全 | **不做错误次数锁定**（本地单用户，删除锁定策略） |
| 19 | 鉴权 | 现有生成类接口开发期**免鉴权**（按推荐），正式版统一 |
| 20 | 资产「改」 | 仅重命名（不改其他信息） |
| 21 | 任务参数策略 | **创建时快照**：进行中任务保持旧参数，新任务用新配置 |
| 22 | 配置页 | **不提供「恢复默认」按钮**，由用户自行配置 |
| 23 | 验证码实现 | **纯 SVG 生成**（零依赖，不装 Pillow） |
| 24 | 资产存储 | **按类型子目录**：`upload/docs`、`upload/images`、`upload/media` |
| 25 | 配音 | 新增**「无配音」模式**（`voice=none`，前端默认选中），跳过语音合成阶段 |

## 4. 详细功能需求

### 4.1 认证模块（9 接口，P0）

| # | 接口 | 说明 |
|:--:|:----|:-----|
| 1 | `GET /api/auth/status` | `{ need_setup: bool }`，前端判定初始化 or 常规登录 |
| 2 | `POST /api/auth/setup` | 初始化管理员（username/password/confirm）→ 创建 + 返回 token |
| 3 | `POST /api/auth/captcha` | 生成 **6 位纯数字** 验证码 → `captcha_id` + SVG 图片（**纯 SVG 生成，零依赖**）；有效期 120s、一次性（内存 dict 存储） |
| 4 | `POST /api/auth/login` | username/password/captcha_id/code → token + 用户信息 |
| 5 | `POST /api/auth/logout` | 登出（token 无状态，前端清 localStorage） |
| 6 | `POST /api/auth/reset-password` | 重置（username + new_password + confirm）→ 成功提示；**成功后 password_version+1** |

| 8 | `PUT /api/users/me` | 修改昵称/头像/邮箱 |
| 9 | `PUT /api/users/me/password` | 修改密码（原密码+新密码）→ 成功后 password_version+1 + 强制重登 |

- 密码：PBKDF2-SHA256（hashlib 内置，盐 16B 随机，迭代 200,000 次）；
- token：自实现 HMAC-SHA256 签名（hmac + hashlib，零新增依赖），7 天有效期，payload 含 `pwd_ver`（改密/重置后旧 token 失效 → 401 强制重登）；
- 验证码：6 位纯数字、纯 SVG 生成、120s 有效、一次性（内存 dict 存储）；
- **不做错误次数锁定**（本地单用户）。

### 4.3 创作生成管线（五步流程，P0）

#### 4.3.1 生成管线

```
路径 A（有配音）:  剧本创作 → 语音合成 → 文生图 → 图生视频 → 视频合成
路径 B（无配音）:  剧本创作 → [跳过语音] → 文生图 → 图生视频 → 视频合成
```

**核心变更：**
1. **语音合成前置**到文生图之前，剧本创作后立即生成分镜语音；
2. **分镜视频时长由分镜语音真实时长驱动**（帧数公式变更），保证画音时长匹配；
3. 新增**「无配音」模式**（`voice=none`，前端默认选中），跳过语音合成阶段。

**分镜视频帧数公式（核心变更）：**

```js
// video-platform/agents/video_creator.py :: calc_frames
const duration = voice_duration        // 有配音：分镜语音真实时长（float，ffprobe 读取）
              || scene.duration        // 无配音/语音失败：LLM 分配的分镜秒数
              || 4;                    // 兜底默认 4 秒
const v_framerate = fps || 16;         // 用户前端选择帧率
const max_fps = 5 * v_framerate + 1;   // 5 秒硬上限（超长视频质量差）
const length = Math.min(max_fps, Math.ceil((duration + 0.3) * v_framerate));
```

| 分镜语音时长 (fps=16) | 帧数 | 实际时长 |
|---|---|---|
| 2.0s | 37 | 2.25s |
| 4.3s | 74 | 4.56s |
| 5.0s | 81 | 5.00s |
| 8.0s | 81 | 5.00s（封顶） |
| 10.0s | 81 | 5.00s（封顶） |

> 超 5 秒的语音：视频截断为 5 秒，合成阶段 `_align_audio_video` 已有"视频减速对齐语音"逻辑（已有），无需改动。

#### 4.3.2 各阶段功能需求

**AI 剧本创作（ScriptWriter）：**
- 调用 LLM（Qwen）根据主题与配置生成完整剧本；
- 剧本结构：标题 + 摘要 + 分镜数组（scene_id、时长、画面描述、旁白、字幕、T2I 英文提示词、I2V 英文提示词、镜头语言）；
- 分镜数量与配置一致，各分镜时长合计约等于目标时长；
- 不同画面风格自动注入风格提示词（t2i_tags / i2v_tags 映射表）；
- 兼容 LLM 非标准输出：自动剥离 ```json 包裹、合并零散 JSON 对象；从 reasoning_content 提取；
- **决策：字幕 = 旁白（一字不差）**，成片烧录字幕与配音文案完全一致；
- 超时 300s 或返回空内容 → 任务失败并给出错误信息。

**AI 文生图（ImageCreator）：**
- 逐分镜使用 T2I 英文提示词调用 ComfyUI 文生图服务（ComfyUIImgClient）生成图片；
- 按（比例 × 分辨率）映射输出图片宽高（640×360 ~ 1920×1080 等 9 档）；
- 图片按 `scene_{编号:03d}.png` 命名保存至项目 images 目录；
- 默认串行生成（并发数 1），避免远程显存压力；
- 单分镜失败不阻断全局，记录错误后继续；请求超时 300s 有明确失败上报。

**AI 图生视频（VideoCreator）：**
- 逐分镜将分镜图片作为输入调用 ComfyUI 图生视频服务（ComfyUIVidClient）Wan2.2 I2V 管线生成片段；
- 使用 high_noise + low_noise 双模型 + LightX2V LoRA 管线；
- **帧数公式：`min(5*fps+1, ceil((voice_duration || scenes.duration || 4 + 0.3) * fps))`**；
- 片段按 `scene_{编号:03d}.mp4` 命名保存至 videos 目录；单镜失败不阻断；超时 300s。

**语音合成（VoiceActor）：**
- 逐分镜将旁白文本（narration）调用 IndexTTS 合成为语音；
- 按配音音色映射 TTS 说话人（男声/女声/童声）与参考音频；支持情感控制参数；
- 语音时长通过 ffprobe 读取（voice_duration），读取失败兜底使用分镜时长；
- **不再合并全片配音**（voiceover.wav 已废弃），逐镜音视频对齐由 VideoComposer 完成；
- ** voice=none 时整个阶段跳过**。

**视频合成（VideoComposer）：**
- 使用 FFmpeg（项目内置 video-platform/bin）合成；
- **逐镜对齐**：每镜画面时长 = max(视频真实时长, 语音时长)——语音短→apad 补静音、视频短→setpts 减速延长；
- concat demuxer 按顺序拼接（每镜已内嵌语音轨）+ ASS 字幕内嵌（字幕区间按对齐后时长累加）；
- **字幕优化**：字号自适应 `max(16, round(width/max_chars*0.95))`；智能换行 `_wrap_subtitle()`；常量 `SUBTITLE_MAX_LINES=2`、`SUBTITLE_MAX_CHARS_BY_RATIO`（16:9→30、9:16→14、1:1→18）；
- 临时文件统一管理（`_temp` 目录），完成后清理。

**任务编排与进度（GenerationManager）：**
- 后台线程异步执行，API 立即返回；步骤顺序：script→voice→images→videos→compose（voice=none 跳过 voice）；
- 进度点：script=5、voice=20、images=35、videos=60、compose=85、done=100（重排后）；
- 前端每 3 秒轮询状态接口（页面隐藏暂停）；
- 任一环节失败：任务标记失败，记录 error_msg；
- **分镜级实时写库**：images/videos/voice 阶段每分镜产物完成即 `upsert_scene` 单条 UPSERT 写库，前端轮询即可实时看到分镜，无需等待整个阶段。

点击 ≤100ms 反馈；首屏骨架屏；错误保留输入 + 字段内联提示 + toast；空状态每页必备；表单防重复提交、回车提交；破坏性操作二次确认（危险按钮暖红）；401 全局拦截登出。

## 5. 数据需求

### 5.1 数据库（SQLite 六表）

- 库文件：`D:\aivideo_v2\sqlite\aivideo.db`；
- 启动自动建库建表（幂等 `CREATE TABLE IF NOT EXISTS`）；**开启 WAL + busy_timeout(5000)**；

**表结构：**

```sql
-- 管理员表（单用户，最多 1 条有效记录）
CREATE TABLE IF NOT EXISTS admin （id            INTEGER PRIMARY KEY AUTOINCREMENT,
  username      TEXT UNIQUE NOT NULL,        -- 登录名
  password_hash TEXT NOT NULL,               -- PBKDF2-SHA256（加盐，严禁明文）
  nickname      TEXT DEFAULT '',
  avatar        TEXT DEFAULT '',
  email         TEXT DEFAULT '',
  password_version INTEGER DEFAULT 0,        -- 改密/重置后 +1，旧 token 失效（强制重登）

-- 项目表（元数据 + 配置快照 + 状态）
CREATE TABLE IF NOT EXISTS projects （id              INTEGER PRIMARY KEY AUTOINCREMENT,
  project_id      TEXT UNIQUE NOT NULL,      -- proj_yyyyMMdd_HHmmss
  name            TEXT NOT NULL,
  topic           TEXT DEFAULT '',
  ratio           TEXT DEFAULT '16:9',
  resolution      TEXT DEFAULT '普清360p 横屏',
  fps             INTEGER DEFAULT 16,
  style           TEXT DEFAULT '写实',
  voice           TEXT DEFAULT 'none',       -- 默认无配音
  target_duration INTEGER DEFAULT 30,
  status          TEXT DEFAULT '等待',        -- 等待/进行中/完成/失败
  error_msg       TEXT DEFAULT '',

  cover_url       TEXT DEFAULT '',           -- 封面 = 第 1 分镜 image_url

-- 分镜表（剧本/图片/视频/配音明细，V2.0 核心新表）
CREATE TABLE IF NOT EXISTS scenes （id            INTEGER PRIMARY KEY AUTOINCREMENT,
  project_id    TEXT NOT NULL REFERENCES projects(project_id),
  scene_no      INTEGER NOT NULL,            -- 1..n
  duration      REAL DEFAULT 5,
  description   TEXT DEFAULT '',             -- 画面描述
  narration     TEXT DEFAULT '',             -- 旁白
  subtitle      TEXT DEFAULT '',             -- 字幕（强制 = narration）

  i2v_prompt    TEXT DEFAULT '',

  video_url     TEXT DEFAULT '',
  voice_path    TEXT DEFAULT '',
  voice_duration REAL DEFAULT 0,             -- 语音真实时长（驱动视频时长）
  status        TEXT DEFAULT '待生成',        -- 待生成/生成中/完成/失败
  UNIQUE(project_id, scene_no)）;

-- 资产表（客户上传附件）
CREATE TABLE IF NOT EXISTS assets （id         INTEGER PRIMARY KEY AUTOINCREMENT,
  file_name  TEXT NOT NULL,
  file_type  TEXT NOT NULL,                  -- 文档/图片/音视频/其他
  ext        TEXT DEFAULT '',                -- 扩展名
  file_size  INTEGER NOT NULL,               -- 字节
  file_path  TEXT NOT NULL,                  -- upload/{docs|images|media}/xxx
  created_at TEXT DEFAULT (datetime('now','localtime'))）;

-- 教程表（Markdown 原文存储，直接发布无草稿态）
CREATE TABLE IF NOT EXISTS tutorials （id          INTEGER PRIMARY KEY AUTOINCREMENT,
  title       TEXT NOT NULL,
  summary     TEXT DEFAULT '',
  cover       TEXT DEFAULT '',
  content     TEXT DEFAULT '',               -- Markdown 原文
  tags        TEXT DEFAULT '',
  is_published INTEGER DEFAULT 1,
  sort_order  INTEGER DEFAULT 0,
  created_at  TEXT DEFAULT (datetime('now','localtime')),
  updated_at  TEXT）;

-- 配置表（系统常量参数，key-value）
CREATE TABLE IF NOT EXISTS settings （id         INTEGER PRIMARY KEY AUTOINCREMENT,
  key        TEXT UNIQUE NOT NULL,
  value      TEXT DEFAULT '',
  updated_at TEXT DEFAULT (datetime('now','localtime'))）;
```

### 5.3 数据一致性设计（核心变更：全部以数据库为准）

**废除 `output/{id}/script.json`**：项目、分镜、配置全部写入 SQLite；文件（图片/视频/音频/成片）仍落盘，但**路径字符串存入数据库**，读取一律走数据库。

**生成管线每步写库时机：**

| 步骤 | 写库内容 |
|:----|:---------|
| 创建项目 | 插入 projects 行（status=等待；**config_snapshot = settings 全量 + 视频配置**） |
| script 完成 | 更新 projects（status=进行中、scene_count）+ 批量插入 scenes 行 |
| images 完成 | 全量替换 scenes（image_url 已填）+ **每分镜实时 upsert_scene** |
| videos 完成 | 全量替换 scenes（video_url 已填）+ **每分镜实时 upsert_scene** |
| voice 完成 | 全量替换 scenes（voice_path/voice_duration 已填）+ **每分镜实时 upsert_scene** |
| compose 完成 | 更新 projects（status=完成、final_video_url、updated_at） |
| 任一步失败 | 更新 projects（status=失败、error_msg、updated_at） |

**常量参数配置化：** LLM/ComfyUI/TTS 等参数从 settings 表读取；**保存配置后立即生效**（后端内存缓存刷新），无需重启；**进行中任务保持创建时的参数快照，新任务使用新配置**。

### 5.4 删除级联规则（弹窗确认后执行）

| 操作 | 数据库 | 物理文件 |
|:----|:-------|:---------|
| 删除项目 | 删 projects 行 + 该 project_id 全部 scenes 行 | 删 `output/{project_id}/` 整目录 |
| 删除资产 | 删 assets 行 | 删 `upload/{docs\|images\|media}/{file}` 文件 |
| 删除教程 | 删 tutorials 行 | 无 |

> 前端删除弹窗展示「将删除 N 个项目/文件，释放约 X MB，不可恢复」，用户确认后执行；`freed_mb = 字节数/(1024*1024)` 四舍五入保留 1 位。

- 数据本地化：主题与生成数据仅用于本系统处理；

## 9. 验收标准

1. 全新部署打开登录页 → 初始化模式（无验证码）→ 创建管理员成功直接进入工作台；再次打开为常规登录；
2. 常规登录：用户名 + 密码 + 6 位纯数字验证码；验证码可刷新、失败不清空输入并自动刷新验证码；
3. 重置密码成功提示，新密码可登录；admin 表密码为加密存储（无明文）；改密/重置后旧 token 失效；
4. **数据一致性**：生成过程中每步完成，SQLite projects/scenes 即时更新；**磁盘无 script.json**；详情/列表/状态全部读库返回；
5. **单并发**：项目进行中再次触发生成 → 400 拒绝；前端按钮置灰 + 可跳转查看进度；
6. 创作页五步流程条与 current_step 对应、四态高亮正确（script→voice→images→videos→compose；voice=none 时语音步骤显示"已跳过"）；
7. 项目列表封面 = 第 1 分镜图片；详情可播放成片/下载/看分镜明细；
8. 删除项目/资产：确认弹窗展示释放空间 → 数据库记录与物理文件同步删除；
9. 资产：大小限制与扩展名白名单**随配置表变化生效**（修改配置后上传即按新规则）；类型筛选/重命名/打开下载可用；
