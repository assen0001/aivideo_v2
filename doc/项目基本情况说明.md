## 1. 项目概述

### 1.1 一句话描述

一套**全链路自动化的 AI 视频生成平台**：用户只需输入一个视频主题，系统即自动完成「剧本创作 →（语音合成）→ 文生图 → 图生视频 → 视频合成」的完整流程，最终输出一条可直接预览、下载的成品视频。

### 1.2 项目最大亮点

> **可本地部署的 AI 长视频创作平台**：大语言模型、文生图、图生视频、语音合成**全链路模型均支持本地化部署**，**无须申请任何第三方平台 API 接口**，**0 成本创作 AI 长视频**。

| AI 能力 | 本地化模型 |
|:--------|:-----------|
| 大语言模型（剧本创作） | Qwen（llama.cpp 推理） |
| 文生图（分镜画面） | z-image-turbo（ComfyUI） |
| 图生视频（分镜动态） | Wan2.2 I2V（ComfyUI） |
| 语音合成（配音） | IndexTTS |

**与云端 AI 视频工具对比：**

| 对比维度 | 本平台（aivideo） | 云端 AI 视频工具 |
|:---------|:------------------|:-----------------|
| 部署方式 | 本地部署，数据不出本机 | 依赖云端 API |
| API 依赖 | 无（全本地模型） | 需申请第三方 API Key |
| 创作成本 | 0 成本（一次性硬件投入） | 按调用量/时长持续计费 |
| 隐私安全 | 数据完全私有 | 数据上云，有泄露风险 |
| 网络依赖 | 可完全离线运行 | 必须联网 |
| 可控性 | 模型/参数完全自主可控 | 受平台限制 |

### 1.3 核心价值

| 特性 | 说明 |
|:-----|:-----|
| 零门槛 | 仅需输入主题 + 简单配置（比例/风格/时长等），无需视频剪辑技能 |
| 全自动化 | 5 个 AI Agent 自动编排，从剧本到成片无需人工干预 |
| 数据可靠 | SQLite 唯一数据源，每步写库，废除 script.json |
| 流程闭环 | 剧本、图像、视频、配音、字幕全链路打通，一站式输出 |
| 成本可控 | AI 能力基于开源模型（ComfyUI + Wan2.2 + Qwen + IndexTTS）组合实现 |
| 自包含运行 | FFmpeg 随项目分发（video-platform/bin），无需单独安装 |

### 1.4 产品定位

面向短视频创作者、教育工作者、市场营销人员及 AI 技术爱好者的本地化 AI 视频生成工具。当前处于**开发/验证阶段**，主体功能已开发完成，具备可运行形态。

## 2. 项目背景与目标

### 2.1 背景

- AIGC 技术成熟（ComfyUI、Stable Diffusion、Wan2.2 等开源模型），大幅降低了视频内容创作门槛；
- 市面上缺乏将「剧本 → 文生图 → 图生视频 → 配音 → 成片」全链路打通的一站式解决方案；
- 现有工具普遍流程碎片化、依赖云端 API（隐私与成本问题）、ComfyUI 工作流配置复杂。

### 2.2 目标

- **短期**：打通全链路视频生成管线，实现「输入主题 → 一键生成视频」（V2.0 已完成，优化画音时长匹配）；
- **中期**：支持风格多样化、分镜微调、历史项目管理；
- **长期**：批量生成、视频模板、多语言支持、在线剪辑（见《需求文档》未来需求章节）。

## 3. 核心功能

### 3.1 视频生成五步管线（核心 P0，顺序）

| 步骤 | Agent | 职责 | 进度节点 |
|:----:|:------|:-----|:--------|
| 1 | ScriptWriter | 调用 LLM（Qwen）生成多分镜剧本（画面描述、旁白、字幕、中英文提示词、镜头语言） | 5% |
| 2 | VoiceActor | 调用 IndexTTS 为分镜旁白生成配音，ffprobe 读取语音真实时长（**前置；voice=none 时跳过**） | 20% |
| 3 | ImageCreator | 调用 ComfyUI 文生图（z-image-turbo），为每个分镜生成图片 | 35% |
| 4 | VideoCreator | 调用 ComfyUI 图生视频（Wan2.2 I2V），**视频时长由分镜语音真实时长驱动** | 60% |
| 5 | VideoComposer | 使用 FFmpeg 逐镜对齐 + 拼接片段 + 内嵌字幕，输出成片 | 85% → 100% |

> **变更：** 语音合成前置到文生图之前；分镜视频帧数公式 `min(5*fps+1, ceil((voice_duration||duration||4+0.3)*fps))`（5 秒硬上限）；新增「无配音」模式（voice=none，前端默认选中）。

### 3.2 前端功能（V2.0 重构）

- **登录**：初始化（无验证码，创建即登录）/ 常规登录（用户名+密码+6位纯数字 SVG 验证码）/ 重置密码；
- **工作台框架**：左右结构（240px 侧栏可折叠 / 移动端抽屉），五导航：创作/项目/资产/教程/配置，头像菜单（资料/改密/官网/退出）；
- **创作页**：五步流程条（四态 + 无配音"已跳过"态）+ 3s 轮询 + 单并发提示 + 失败重试；
- **项目页**：卡片网格（封面=第1分镜）+ 筛选/关键词/滚动加载 + 详情（成片播放/下载/删除级联/分镜明细）；
- **资产页**：拖拽多文件上传（配置限大小/白名单）+ 类型 Tab + 仅重命名 + 删除级联；
- **教程页**：Markdown 渲染 + 直接发布（无草稿）+ 编辑/删除；
- **配置页**：五大分组（LLM/文生图/图生视频/TTS/上传限制）可视化维护，敏感字段掩码，保存立即生效；
- **视觉体系**：「温暖亲和」（米白/奶油/焦糖棕/琥珀橙），开源字体，响应式 + WCAG 2.1 AA。

### 3.3 支持的可选配置

| 配置项 | 可选值 |
|:-------|:-------|
| 画面比例 | 16:9 横屏、9:16 竖屏、1:1 方形 |
| 分辨率 | 普清360p、高清720p、超清1080p（**只传等级，方向由比例自动补全**） |
| 帧率 | 16 / 24 / 30 fps（默认 16） |
| 画面风格 | 写实、动画、动漫、3D、赛博朋克、水墨风、像素风、油画风 |
| 配音音色 | **无配音（默认）** / 温柔女声、明亮女声、浑厚男声、温暖男声、童声 |
| 目标时长 | 10~60 秒（分镜数 = 时长/5 秒，3~12 个） |

## 7. 核心模块说明

| 模块 | 关键设计 |
|:-----|:---------|
| DB（services/db.py） | SQLite 六表 DAO；WAL + busy_timeout(5000)；短事务；settings 内存缓存 + 刷新；教程 doc 导入；启动恢复（进行中→失败） |
| AuthService | PBKDF2-SHA256（迭代 200k）；token 自实现 HMAC 签名（7 天 + pwd_ver 强制重登）；6 位纯数字 SVG 验证码（120s 一次性，零依赖） |
| GenerationManager | 单并发全局锁；创建时配置快照注入（Agent 不读 settings）；每步写库；分镜级实时写库（upsert_scene） |
| LLMClient | OpenAI 兼容；reasoning_content 提取；多级 JSON 清理；超时 300s；参数化构造 |
| ComfyUIImgClient | 文生图专用；Bearer Token；超时 300s/轮询 5s；get_system_stats 健康检查 |
| ComfyUIVidClient | 图生视频专用；超时 300s/轮询 10s；上传图→I2V→下载 |
| ScriptWriter | STYLE_PROMPT_MAP 风格标签注入；字幕=旁白；Qwen 输出 JSON 解析 |
| ImageCreator | RESOLUTION_MAP 宽高映射；默认串行（MAX_PARALLEL=1）；单镜失败不阻断 |
| VideoCreator | **帧数公式**：`min(5*fps+1, ceil((voice_duration‖duration‖4+0.3)*fps))`；Wan2.2 双模型 + LoRA |
| VoiceActor | 音色映射 + 参考音频 + 情感控制；ffprobe 读 voice_duration；不合并全片配音；支持 voice=none 跳过 |
| VideoComposer | 逐镜对齐（apad/setpts）；concat + ASS 字幕内嵌；字幕字号自适应 + 智能换行；_temp 临时目录 |
| FFmpegUtils | 简化为常量入口（固定 bin/，无查找兜底） |

## 9. 数据流

### 9.1 生成流程

```
POST /api/projects → 创建 Project(等待) + config_snapshot 快照入库
  → POST /generate → GenerationManager 后台线程启动（单并发锁）
  → ScriptWriter   → LLM 生成分镜剧本 → 写库（进行中 + scenes）
  → VoiceActor     → 逐镜 IndexTTS 配音 → ffprobe 读时长 → 写库（voice=none 跳过）
  → ImageCreator   → 逐镜 ComfyUIImgClient 文生图 → 写库
  → VideoCreator   → 逐镜 ComfyUIVidClient 图生视频（语音驱动帧数）→ 写库
  → VideoComposer  → FFmpeg(bin) 逐镜对齐+拼接+字幕 → 成片
  → 前端轮询 status 至 100% → 播放/下载
```

### 9.2 产物目录

```
output/{project_id}/
├── images/scene_001.png   # 分镜图片（scene_{编号:03d}.png）
├── videos/scene_001.mp4   # 分镜视频片段
├── audio/scene_001.wav    # 分镜级配音（无合并 voiceover.wav）
└── final/{project_id}.mp4 # 最终合成视频
```

## 12. 已知问题与风险

### 12.1 安全问题（建议优先处理）

| 风险 | 位置 | 说明 |
|:-----|:-----|:-----|
| API 凭据明文 | services 模块 / settings 表 / 历史文档 | LLM Key、ComfyUI Token、TTS 密码测试环境明文。**用户已确认：测试环境暂不处理，后期部署时迁移环境变量**；合并文档敏感值已脱敏，旧文档归档 |

### 12.2 工程问题

| 问题 | 说明 |
|:-----|:-----|
| 线程安全 | 生成任务 threading.Thread 后台执行，单并发锁保护；生产可替换 Celery/任务队列 |
| 并发限制 | 单并发串行（设计决策）；多项目并行会相互阻塞 |
| 环境依赖 | 外部服务（ComfyUI×2/LLM/TTS）依赖特定域名/内网可达性 |
| 联调 | 语音驱动时长/无配音路径未做真实全管线验证 |
