## 1. 项目简介

### 1.1 产品定位

本地视频智造平台是一套 **全链路 AI 视频生成系统**。用户只需输入一个视频主题，系统即可自动完成以下完整流程：

```
输入主题 → AI 剧本创作 → [语音合成] → 文生图 → 图生视频 → 视频合成 → 成品视频
```

> **变更说明**：语音合成阶段前置到文生图之前；支持「无配音」模式（跳过语音合成，分镜视频时长回退由 scenes.duration 决定）。

全程无需手动操作中间环节，无需专业视频编辑技能。

> **💡 项目最大亮点：** 可本地部署的 AI 长视频创作平台 —— 大语言模型（Qwen）、文生图（z-image-turbo）、图生视频（Wan2.2 I2V）、语音合成（IndexTTS）**全链路模型均支持本地化部署**，无须申请任何第三方平台 API 接口，**0 成本创作 AI 长视频**；数据全程不出本地，可完全离线运行。

### 1.2 核心理念

- **零门槛**：用户只需输入主题和简单配置，一键生成视频；
- **全自动化**：从剧本到最终视频，全部由 AI Agent 自动编排；
- **数据可靠**：SQLite 唯一数据源，每步写库，废除 script.json；
- **隐私安全**：单用户本地部署，数据存储在本地。

## 5. 核心模块说明

### 5.1 数据模型层（`models/project.py`）

**职责：** 定义整个系统的所有数据结构，包括视频配置、分镜、项目等。

#### 5.1.1 枚举类型

| 枚举类 | 值 | 说明 |
|:-------|:-----|:-----|
| `VideoRatio` | `16:9`, `9:16`, `1:1` | 视频比例 |
| `VideoResolution` | `普清360p`, `高清720p`, `超清1080p` | 分辨率等级（**不含横竖屏，方向由比例补全**） |
| `VideoStyle` | `写实`, `动画`, `动漫`, `3D`, `赛博朋克`, `水墨风`, `像素风`, `油画风` | 视频风格 |
| `VoiceStyle` | `none`, `浑厚男声`, `温暖男声`, `温柔女声`, `明亮女声`, `童声` | 配音音色（**新增 NONE = "none"**） |
| `SceneCamera` | `大远景`, `远景`, `中景`, `近景`, `特写`, `左移`, `右移`... | 镜头语言 |
| `TaskStatus` | `等待`, `进行中`, `完成`, `失败` | 任务状态 |

> **分辨率方案（前端只传等级，方向由比例决定）：**
> 前端 `分辨率` 下拉框仅提供 `普清360P / 高清720P / 超清1080P` 三个等级（不含横竖屏）。
> `POST /api/projects` 创建时，后端 `_resolve_resolution(grade, ratio)` 根据画面比例自动补全方向
> 后写入 DB：`16:9 → 横屏`、`9:16 → 竖屏`、`1:1 → 横屏`（与 RESOLUTION_MAP 的 1:1 key 一致）。
> 非法等级/比例返回 400。此方案从根上消除「9:16 + 横屏」类错配。

#### 5.1.2 核心数据类

**VideoConfig（视频配置）**
- `ratio` / `resolution` / `fps` / `style` / `voice` / `bgm_style`（保留兼容）/ `target_duration` / `scene_count`

**Scene（分镜）**
- `scene_id` / `duration` / `description` / `narration` / `subtitle`（**强制 = narration**）
- `t2i_prompt` / `i2v_prompt` / `camera`
- `image_path` / `video_path` / `voice_path` / **`voice_duration`（语音真实时长，驱动视频帧数）**
- `status`

**Project（项目）**
- `project_id` / `name` / `topic` / `config` / `scenes[]` / `audio_path` / `final_video_path` / `status` / `created_at`

### 5.2 AI Agent 层

#### 5.2.1 ScriptWriter — 剧本创作

**文件：** `video-platform/agents/script_writer.py`

**工作流程：**
1. 接收用户输入的视频主题和配置；
2. 根据视频风格选择对应的 Prompt 修饰词（`STYLE_PROMPT_MAP`）；
3. 构造系统 Prompt（`SYSTEM_PROMPT`），指导 LLM 生成 JSON 格式剧本；
4. 调用 `LLMClient.chat()` 获取模型输出（从 reasoning_content + content 提取，多级 JSON 清理）；
5. 解析 JSON，构建 `Project` 对象，包含所有分镜信息。

**关键设计：**
- 每种视频风格预定义 `t2i_tags`（文生图标签）和 `i2v_tags`（图生视频标签）；
- **决策：字幕 = 旁白（一字不差）**，成片烧录字幕（ASS）与配音文案完全一致；
- 超时 300s 或返回空内容 → 任务失败并给出错误信息。

**扩展点：** 新增风格在 `STYLE_PROMPT_MAP` 添加映射；修改生成逻辑调整 `SYSTEM_PROMPT`。

#### 5.2.2 VoiceActor — 配音生成（前置到 Step 2）

**文件：** `video-platform/services/voice_actor.py`

**工作流程：**
1. 遍历所有分镜，获取 `scene.narration` 文本；
2. 根据 `VoiceStyle` 选择音色（male / female / child，参考音频 `SPEAKER_URLS`）；
3. 调用 Index-TTS Gradio 客户端生成音频（每分镜独立 `scene_{n}.wav`），支持情感控制（`emo_control_method`）；
4. **ffprobe 读取真实时长 → scene.voice_duration**（读取失败兜底 scene.duration）；
5. **不再合并全片配音**（`_merge_audio_segments` 与 voiceover.wav 已删除），逐镜对齐由 VideoComposer 完成；
6. ** `voice=none` 时整个阶段跳过**（`generation.py` 按快照中 voice 判断）。

**扩展点：** 新增音色在 `VOICE_MAP` 和 `SPEAKER_URLS` 中添加。

#### 5.2.3 ImageCreator — 文生图

**文件：** `video-platform/agents/image_creator.py`

**工作流程：**
1. 遍历所有分镜，从 `scene.t2i_prompt` 获取提示词；
2. 调用 `ComfyUIImgClient.generate_t2i()` 提交文生图任务；
3. 轮询等待完成（5s 间隔，超时 300s），获取图片路径；
4. 重命名为 `scene_{scene_id:03d}.png`。

**关键设计：**
- 分辨率映射表 `RESOLUTION_MAP`：根据 `(比例, 分辨率)` 返回 `(width, height)`（640×360 ~ 1920×1080 等 9 档）；
- 默认串行生成（`MAX_PARALLEL = 1`），保证显存稳定；
- 失败不阻断，记录日志并继续处理其他分镜；
- **支持 `on_scene_done(scene)` 回调**：每分镜完成即写库。

**扩展点：** 调整 `MAX_PARALLEL`；新增分辨率档位需同步枚举与映射表。

#### 5.2.4 VideoCreator — 图生视频（帧数公式）

**文件：** `video-platform/agents/video_creator.py`

**工作流程：**
1. 遍历所有分镜，获取 `scene.image_path` 和 `scene.i2v_prompt`；
2. **计算帧数（语音驱动）：**

```python
# calc_frames()
duration = scene.voice_duration or scene.duration or 4   # 语音真实时长 → 分镜时长 → 兜底 4s
max_fps = 5 * fps + 1                                    # 5 秒硬上限
frames  = min(max_fps, math.ceil((duration + 0.3) * fps))
```

3. 调用 `ComfyUIVidClient.generate_i2v()`（high_noise + low_noise 双模型 + LightX2V LoRA 管线）；
4. 重命名输出视频为 `scene_{scene_id:03d}.mp4`。

**关键设计：**
- Wan2.2 双模型 + LightX2V LoRA pipeline；超时 300s；
- **5 秒硬上限**：长配音（>5s）视频截断为 5 秒，合成阶段减速对齐语音。

**扩展点：** 修改帧数策略调整 `calc_frames()`。

#### 5.2.5 VideoComposer — 视频合成

**文件：** `video-platform/agents/video_composer.py`

**工作流程（逐镜对齐 + 字幕优化）：**
1. **逐镜音视频对齐**（`_align_audio_video`）：每镜画面时长 = max(视频真实时长(ffprobe), 语音时长)
   - 语音短 → 画面不变速，语音 `apad` 补静音到画面时长；
   - 视频短 → 画面 `setpts` 减速延长到语音时长（保留完整配音，不截断）；
2. **拼接分镜视频**：FFmpeg `concat demuxer` 按顺序拼接（每镜已内嵌语音轨）；
3. **最终渲染**：concat 视频 + ASS 字幕内嵌（字幕区间按对齐后时长累加，与语音同步）；
4. 清理临时文件（`_temp` 目录）。

**字幕变更（9:16 越界修复）：**
1. **字号自适应**：`font_size = max(16, round(width / max_chars * 0.95))`，按画面宽度推导；
2. **智能换行**：`_wrap_subtitle()` 优先在标点处断行，无标点长串按字符数兜底硬切；超过 `SUBTITLE_MAX_LINES`(2) 行截断补省略号；
3. **可调常量**：`SUBTITLE_MAX_LINES = 2`；`SUBTITLE_MAX_CHARS_BY_RATIO`（16:9 → 30，9:16 → 14，1:1 → 18）。

> **重要变更说明**：不再使用全片配音 voiceover.wav（旧实现覆盖逐镜音轨且 atrim 截断语音）。`audio_path/bgm_path` 参数保留仅为兼容旧调用，内部不再混音。

**扩展点：** `_concat_videos()` 添加 xfade 转场；`_final_render()` 调整字幕/水印。

#### 5.2.6 GenerationManager — 总编排（V2.0 起替代 orchestrator）

**文件：** `video-platform/services/generation.py`

**职责：** 编排整条视频生产管线，按顺序执行各 Agent，统一执行写库。

**工作流：**

```
Step 1: ScriptWriter → 生成剧本（5%）
Step 2: VoiceActor  → 生成配音（20%，voice=none 跳过）
Step 3: ImageCreator → 生成分镜图片（35%）
Step 4: VideoCreator → 生成分镜视频（60%）
Step 5: VideoComposer → 合成最终视频（85% → 100%）
```

**关键设计：**
- **单并发锁**：同一时间仅 1 项目「进行中」，重复触发 400；
- **按快照构建客户端**：每次 generate 按 projects.config_snapshot 构建 LLM/ComfyUI/TTS 客户端（Agent 不直接读 settings）；
- **每步写库**（短事务）：见 §7 数据流；
- **分镜级实时写库**：images/videos/voice 阶段注入 `on_scene_done(scene)` 回调，每分镜完成即 `db.upsert_scene()` 单条 UPSERT 写库；step 末尾 `upsert_scenes()` 兜底；
- **状态增强**：status='等待' 且内存进度存在时，接口返回内存 step/progress，前端立即显示 script 阶段 running；
- 异常处理：任一步失败 → 更新 projects 失败 + error_msg + 释放锁。

### 5.3 基础设施服务层

#### 5.3.1 DB — SQLite DAO（V2.0 核心新模块）

**文件：** `video-platform/services/db.py`

**职责：** 连接管理（WAL + busy_timeout(5000)）、六表 CRUD（短事务）、settings 配置缓存 + 刷新、教程 doc 导入、启动恢复钩子（`recover_interrupted_projects`：进行中→失败）。

**关键约定：** 每个 DAO 方法内 `with get_connection()` + `with conn:` 短事务；写操作不跨步骤持有连接；`load_settings()` 首次查库缓存，`refresh_settings_cache()` PUT 后刷新立即生效。

#### 5.3.2 LLMClient — LLM 推理客户端

**文件：** `video-platform/services/llm_client.py`

**关键设计：** OpenAI 兼容 API；推理模型适配（reasoning_content 提取）；Markdown JSON 清理；超时 300s；**参数化构造**（api_base/api_key/model/timeout 由快照注入，V2.0 起删除模块级硬编码）。

#### 5.3.3 ComfyUIImgClient / ComfyUIVidClient — ComfyUI 客户端（拆分）

| 客户端 | 文件 | 服务地址 | 特点 |
|:-------|:-----|:---------|:-----|
| ComfyUIImgClient | `services/comfyui_img.py` | 内网（settings.t2i_url） | 文生图；T2I 超时 300s/轮询 5s；get_system_stats 供健康检查 |
| ComfyUIVidClient | `services/comfyui_vid.py` | 内网（settings.i2v_url） | 图生视频；上传图片 → I2V 工作流；超时 300s/轮询 10s |

**关键设计：** Bearer Token 认证；**参数化构造**（base_url/token/timeout/poll_interval 由快照注入）。

#### 5.3.4 FFmpegUtils — FFmpeg 路径（V2.6 动态解析）

**文件：** `video-platform/services/ffmpeg_utils.py`

**关键设计：** **动态解析（V2.6）**：`get_ffmpeg_path()/get_ffprobe_path()` 按「项目内置 `video-platform/bin/`（基于 `__file__` 定位）→ 系统 `PATH`（`shutil.which`）」顺序查找；两者均未找到时抛 `FileNotFoundError`，错误信息提示用户下载 ffmpeg 放入 bin 目录或加入系统 PATH（FFmpeg 二进制不再随仓库分发）。保留 `FFMPEG_PATH/FFPROBE_PATH` 常量仅供旧引用兼容，新代码一律使用 get_* 函数。

### 5.4 后端主程序

**文件：** `main.py`

**职责：** FastAPI 应用入口，提供 REST API。

### 6.2 六表结构

```sql
-- 管理员表（单用户，最多 1 条有效记录）
CREATE TABLE IF NOT EXISTS admin （id            INTEGER PRIMARY KEY AUTOINCREMENT,
  username      TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,               -- PBKDF2-SHA256（加盐，严禁明文）
  nickname      TEXT DEFAULT '',
  avatar        TEXT DEFAULT '',
  email         TEXT DEFAULT '',
  password_version INTEGER DEFAULT 0,        -- 改密/重置后 +1，旧 token 失效
  created_at    TEXT DEFAULT (datetime('now','localtime'))）;

-- 项目表
CREATE TABLE IF NOT EXISTS projects （id              INTEGER PRIMARY KEY AUTOINCREMENT,
  project_id      TEXT UNIQUE NOT NULL,      -- proj_yyyyMMdd_HHmmss
  name            TEXT NOT NULL,
  topic           TEXT DEFAULT '',
  ratio           TEXT DEFAULT '16:9',
  resolution      TEXT DEFAULT '普清360p 横屏',
  fps             INTEGER DEFAULT 16,
  style           TEXT DEFAULT '写实',
  voice           TEXT DEFAULT 'none',       -- 默认无配音
  target_duration INTEGER DEFAULT 30,
  status          TEXT DEFAULT '等待',        -- 等待/进行中/完成/失败
  error_msg       TEXT DEFAULT '',
  scene_count     INTEGER DEFAULT 0,
  cover_url       TEXT DEFAULT '',
  final_video_url TEXT DEFAULT '',
  config_snapshot TEXT DEFAULT '',           -- 创建时 settings 全量 + 视频配置 JSON
  created_at      TEXT DEFAULT (datetime('now','localtime')),
  updated_at      TEXT）;

-- 分镜表
CREATE TABLE IF NOT EXISTS scenes （id            INTEGER PRIMARY KEY AUTOINCREMENT,
  project_id    TEXT NOT NULL REFERENCES projects(project_id),
  scene_no      INTEGER NOT NULL,
  duration      REAL DEFAULT 5,
  description   TEXT DEFAULT '',
  narration     TEXT DEFAULT '',
  subtitle      TEXT DEFAULT '',             -- 强制 = narration
  t2i_prompt    TEXT DEFAULT '',
  i2v_prompt    TEXT DEFAULT '',
  camera        TEXT DEFAULT '',
  image_url     TEXT DEFAULT '',
  video_url     TEXT DEFAULT '',
  voice_path    TEXT DEFAULT '',
  voice_duration REAL DEFAULT 0,             -- 语音真实时长（驱动视频时长）
  status        TEXT DEFAULT '待生成',
  UNIQUE(project_id, scene_no)）;

-- 资产表
CREATE TABLE IF NOT EXISTS assets （id         INTEGER PRIMARY KEY AUTOINCREMENT,
  file_name  TEXT NOT NULL,
  file_type  TEXT NOT NULL,                  -- 文档/图片/音视频/其他
  ext        TEXT DEFAULT '',
  file_size  INTEGER NOT NULL,
  file_path  TEXT NOT NULL,                  -- upload/{docs|images|media}/xxx
  created_at TEXT DEFAULT (datetime('now','localtime'))）;

-- 教程表
CREATE TABLE IF NOT EXISTS tutorials （id          INTEGER PRIMARY KEY AUTOINCREMENT,
  title       TEXT NOT NULL,
  summary     TEXT DEFAULT '',
  cover       TEXT DEFAULT '',
  content     TEXT DEFAULT '',               -- Markdown 原文
  tags        TEXT DEFAULT '',
  is_published INTEGER DEFAULT 1,            -- 直接发布，恒 1
  sort_order  INTEGER DEFAULT 0,
  created_at  TEXT DEFAULT (datetime('now','localtime')),
  updated_at  TEXT）;

-- 配置表（key-value）
CREATE TABLE IF NOT EXISTS settings （id         INTEGER PRIMARY KEY AUTOINCREMENT,
  key        TEXT UNIQUE NOT NULL,
  value      TEXT DEFAULT '',
  updated_at TEXT DEFAULT (datetime('now','localtime'))）;
```

## 7. 数据流详解

### 7.1 完整视频生成流程

```
用户输入主题
    │
    ▼
后端创建 Project（status=等待）+ config_snapshot 快照入库
    │
    ▼
后端启动后台线程执行生成管线（GenerationManager.run）
    │
    ▼
┌─────────────────────────────────────────┐
│ Step 1: ScriptWriter 剧本创作（5%）      │
│   - 构造 LLM Prompt → 调用 Qwen          │
│   - 解析 JSON → Project.scenes[]         │
│   - 写库：status=进行中 + upsert_scenes  │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ Step 2: VoiceActor 配音生成（20%，可选） │
│   - voice=none 时整个阶段跳过    │
│   - 逐镜 Index-TTS 生成 wav              │
│   - ffprobe 读 voice_duration            │
│   - 每分镜 upsert_scene（实时）     │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ Step 3: ImageCreator 文生图（35%）       │
│   - 逐镜 ComfyUIImgClient 文生图         │
│   - 每分镜 upsert_scene（实时）          │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ Step 4: VideoCreator 图生视频（60%）     │
│   - 帧数 = min(5*fps+1, ceil((voice_duration │
│     || scenes.duration || 4 + 0.3)*fps))  │
│   - 逐镜 ComfyUIVidClient 图生视频       │
│   - 每分镜 upsert_scene（实时）          │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ Step 5: VideoComposer 视频合成（85%）    │
│   - 逐镜对齐：时长=max(视频,语音)        │
│   - FFmpeg 拼接分镜画面（含内嵌音轨）    │
│   - 合成最终视频（+字幕）                │
│   - 写库：status=完成 + final_video_url  │
└─────────────────────────────────────────┘
    │
    ▼
前端轮询 status=完成 → 播放/下载成片
```

### 7.2 写库时机汇总

| 步骤 | 写库内容 |
|:----|:---------|
| 创建项目 | 插入 projects 行（status=等待，config_snapshot） |
| script 完成 | 更新 projects（进行中、scene_count）+ upsert_scenes |
| voice/images/videos | 每分镜 upsert_scene（实时）+ step 末尾 upsert_scenes 兜底 |
| compose 完成 | 更新 projects（完成、final_video_url） |
| 任一步失败 | 更新 projects（失败、error_msg） |

### 7.3 前端状态流转

```
用户配置参数 → ConfigForm.submit → POST /api/projects → POST /generate
    ▼
CreateView 启动 3s 轮询 GET /status（document.hidden 暂停）
    ▼
current_step 更新 StepFlow 五步状态（script→voice→images→videos→compose）
    ▼
status=完成 → 流程条全✓ → 播放成片
status=失败 → 对应步骤红 ✗ + 错误卡片 → 回到开始创作
```

**错误码：** 400（并发/参数）、401（未登录/token 失效）、403（非法路径）、404（不存在）、422（校验失败）、500（内部）。

## 13. 注意事项与最佳实践

### 13.1 显存管理

- 文生图和图生视频均使用远程 ComfyUI 服务，本地无需 GPU；
- 如需本地部署 ComfyUI，建议显存 ≥ 16GB；
- RTX 3060 12GB 本机场景注意：ComfyUI 与本地推理服务共享显存，长任务存在 OOM 风险。

### 13.2 超时设置（默认）

- LLM：300 秒；文生图：300 秒（轮询 5s）；图生视频：300 秒（轮询 10s）；前端轮询：3 秒。

### 13.3 错误处理

- 单分镜失败不阻断全局流程，记录错误后继续；
- 前端在轮询时忽略临时网络错误，持续重试；
- 最终失败时返回明确的错误信息（error_msg 入库，前端展示）。

### 13.4 数据备份

- 定期备份 `sqlite/aivideo.db`（唯一数据源）；
- 定期备份 `output/`（生成产物）与 `upload/`（资产）；
- 删除操作会级联删除物理文件，删除前有确认弹窗。

### 13.5 敏感信息

- ⚠️ **开发期凭据明文问题**：测试环境 API Key/Token/密码明文存在于代码与配置表，**部署前必须迁移至环境变量或脱敏管理**；
- 文档（doc/*.md）会被自动导入为教程并在教程页可见，**不要在文档中写明文凭据**（本文档敏感值已脱敏）。

## 14. 常见问题

| 问题 | 可能原因 | 解决方案 |
|:----|:---------|:---------|
| 后端启动报错 `ModuleNotFoundError` | 缺少依赖包 | `pip install -r requirements.txt`（或激活 .venv） |
| 前端启动报错 | node_modules 未安装 | `cd video-frontend && npm install` |
| 上传接口报错 | 缺 python-multipart | `pip install python-multipart` |
| ComfyUI 连接失败 | URL 或 Token 错误 | 配置页检查文生图 / 图生视频服务的 Token |
| 视频合成失败 | FFmpeg 缺失 | 下载 ffmpeg.exe 放入 video-platform/bin/ 或加入系统 PATH（程序会报错提示） |
| 语音时长读取为 0 | ffprobe 缺失 | 下载 ffprobe.exe 放入 video-platform/bin/ 或加入系统 PATH |
| 登录后旧 token 失效 | 服务重启（密钥内存态）或改密 | 重新登录即可（本地单用户） |
| 教程页显示内部文档 | doc/*.md 被自动导入 | 属设计行为；可在教程页编辑/删除 |
| 分镜视频时长异常 | 语音驱动公式未生效 | 确认 voice_duration 已写库；无配音走 scenes.duration |
